# Машина согласия

Простой статический сайт с Python-сервером для API и хранения ответов.
Копия репозитория [NikitaSeitov/web-2](https://github.com/NikitaSeitov/web-2), адаптированная для запуска под **Windows 7**.

## Запуск на Windows 7

### Что нужно установить (один раз)

1. **Python 3.8.10** — последняя версия Python, которая работает на Windows 7
   (более новые, в т.ч. 3.9+, на Win7 не запускаются).
   Установщик: <https://www.python.org/downloads/release/python-3810/>
   - 64-битная Windows: `Windows x86-64 executable installer`
   - 32-битная Windows: `Windows x86 executable installer`
   - при установке отметьте **Add Python 3.8 to PATH**.
   - если установщик ругается на `api-ms-win-crt-*.dll`, установите обновления Windows 7 SP1,
     KB2533623 и KB2999226 (Universal C Runtime).
2. **Браузер**: Google Chrome 109 (последний для Win7) или Firefox 115 ESR.
   Внешние библиотеки и интернет сайту не нужны — всё работает локально.

### Запуск

Двойной клик по `start_exhibition.bat`. Скрипт:

- сам находит Python (в `PATH`, через `py`, в стандартных папках установки Python 3.8
  или в папке `python\` рядом со скриптом — туда можно распаковать портативный Python 3.8);
- запускает `server.py` в отдельном окне (его не закрывать — это сервер);
- открывает `http://localhost:8000/` в Chrome в режиме киоска (или в Firefox, или в браузере
  по умолчанию). Выход из киоска — `Alt+F4`.

При первом запуске брандмауэр Windows может спросить разрешение для Python — можно разрешить
или отказать, на локальную работу это не влияет.

Вручную:

```bat
cd папка-с-проектом
python server.py
```

и открыть <http://localhost:8000>.

### server.exe (необязательно)

Исходный `dist/server.exe` был собран на Python 3.14 и на Windows 7 не запускался, поэтому он удалён.
Если нужен exe без установки Python на выставочном компьютере — соберите его на любой машине
с Python 3.8 скриптом `build_exe_win7.bat` (использует PyInstaller 5.13.2, который ещё поддерживает Win7).
Готовый `dist\server.exe` положите в папку проекта рядом с `index.html` и `data\`.

## Что делает сервер

- обслуживает статические файлы сайта (с поддержкой Range-запросов для видео)
- сохраняет ответы в `data/responses.json`
- возвращает статистику через `GET /api/statistics`
- принимает ответы через `POST /api/responses`

`server.js` — альтернативный сервер на Node.js/Express (не используется при запуске через `.bat`).
